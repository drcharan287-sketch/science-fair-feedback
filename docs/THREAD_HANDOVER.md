3. **Feedback has no manual approval queue:** valid actual submissions are saved automatically to the protected `Feedback` Sheet. Private Admin still has on-demand original/translated review drilldown and audited exceptional vote exclusion; it does not require students or staff to approve every submitted review.
4. **iOS Chrome/Safari translation fallback:** inline English preview uses a hidden cross-origin no-save HTML POST and can fail on iOS browser engine restrictions. After reviewing/editing the original, select **Open English translation in a separate tab**, which sends a user-initiated top-level `action=translatePreview` POST (not a vote). The translated result appears in a Google-hosted separate tab; return to Voting to submit if appropriate. iOS asks for a single utterance rather than continuous speech; no claim of guaranteed speech or translation support for all 22 languages.
